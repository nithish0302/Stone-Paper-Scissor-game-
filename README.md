# Stone Paper Scissor Game

A simple Stone Paper Scissor game made using HTML, CSS, and JavaScript.

The player can choose Stone, Paper, or Scissor and play against the computer.

## 🎮 Features

- Play against the computer
- Random computer move
- Win, lose, and tie score
- Score saved using `localStorage`
- Reset score button
- Responsive design

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/nithish0302/Stone-Paper-Scissor-game-.git
```

2. Open the project folder.
3. Open `index.html` in your browser.
4. Start playing.

## 📌 Game Rules

- Stone beats Scissor
- Scissor beats Paper
- Paper beats Stone
- Same choice results in a Tie
